
# [1.0.8.2] - 2026-01-10 (Финальный патч)

### Исправлено - КРИТИЧЕСКИЙ ФИКС TIMEZONE 🔧
- **FileProcessor::processFiles():** Исправлено сравнение `file_last_modified` с приведением к UTC
- Проблема: при сравнении `$firstRecord->file_last_modified` (Carbon объект) с `$fileLastModified` (UTC строка) Carbon приводился к строке в timezone приложения, что могло вызывать ложное несоответствие и лишний `truncate()` + перезагрузку temp таблицы
- Решение: явное приведение `$firstRecord->file_last_modified` к UTC строке перед сравнением
- Эффект: 100% гарантия корректного определения актуальности файлов независимо от `app.timezone` и MySQL session timezone

# [1.0.8] - 2026-01-10

### Добавлено - АВТОМАТИЗАЦИЯ ИМПОРТА 🤖
- **Атомарное обновление файлов:** DebugExchangeController теперь автоматически создаёт/обновляет файлы `storage/app/1c_debug/current/import.xml` и `current/offers.xml` через временные файлы + rename
- **Artisan-команда:** `php artisan mallimport1c:run` для автоматической батч-обработки импорта
  - Параметр `--batch=N` для настройки размера батча (по умолчанию 250)
  - Cache lock для защиты от параллельных запусков (TTL: 15 минут)
  - Автоматический выход при отсутствии pending записей
  - Детальный вывод статистики обработки
- **Фильтрация по timestamp:** TempImportService и MallSyncService теперь поддерживают фильтрацию pending записей по `file_last_modified` для обработки только актуального батча
- **Методы статистики:** `countPending()`, `countProcessed()`, `countErrors()` в TempImportService
- **Документация:** Полное руководство по автоматизации в [docs/AUTOMATION.md](docs/AUTOMATION.md)

### Изменено
- **Конфигурация:** `import_path` изменён на `storage/app/1c_debug/current/`, файлы переименованы в `import.xml` и `offers.xml`
- **MallSyncService::processBatch():** Добавлен опциональный параметр `$fileLastModified` для фильтрации батча
- **TempImportService::getPendingItems():** Добавлен опциональный параметр `$fileLastModified`

### Совместимость
- ✅ Обратная совместимость: все изменения опциональны, старый код продолжит работать
- ✅ Ручной импорт через админ-панель работает без изменений
