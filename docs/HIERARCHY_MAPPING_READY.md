## 🎯 ПРИНЦИП РАБОТЫ

### Алгоритм маппинга:
1. **Приоритет 1**: Поиск по справочнику "Категория для сайта"
2. **Приоритет 2**: Поиск по группе товара
3. **Иерархический поиск**: Если группа не найдена, ищем корневую группу
4. **Fallback**: Категория "Без категории"

### Пример иерархического маппинга:
```
Товар "Парфюмерная вода BTSO" 
├── group_id: BTSO (подгруппа)
├── Прямого соответствия нет в Mall
├── Система находит корневую группу ПАРФЮМЕРИЯ
└── Результат: категория ПАРФЮМ (ID: 74) ✅
```

## 🚀 ГОТОВЫЕ ВОЗМОЖНОСТИ

### ✅ Что работает:
- Двухуровневое маппинг (справочники → группы → fallback)
- Иерархический поиск корневых категорий
- Сохранение ручных изменений админа
- Кеширование для производительности
- Обработка справочников из новой структуры XML
- Fallback на категорию по умолчанию

### 📊 Статистика:
- **96 категорий** в Mall (34 с кодами, 62 без кодов)
- **85 групп** в XML-иерархии (3 уровня вложенности)
- **3 корневые группы** с настроенными кодами
- **Иерархия**: 12 корневых → 64 уровень-1 → 9 уровень-2

## 🔧 КАК ИСПОЛЬЗОВАТЬ

### В коде импорта:
```php
use Dmdev\MallImport1c\Services\CategoryMappingService;

$mappingService = new CategoryMappingService();

// Для товара с справочником категории сайта
$categoryId = $mappingService->getMallCategoryId(
    $websiteCategoryId, // из справочника "Группа Номенклатуры для сайта"  
    $productGroupId     // ID группы товара из XML
);

// Результат: ID категории Mall или 77 (fallback)
```
